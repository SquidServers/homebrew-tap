# SquidServers Homebrew Tap

Official Homebrew tap for [SquidServers](https://squidservers.com) — Simple local Minecraft server hosting.

## Installation

To install SquidServers on macOS via Homebrew Cask:

```bash
brew tap SquidServers/tap
brew install --cask squidservers
```

Or install directly in a single command:

```bash
brew install --cask squidservers/tap/squidservers
```

## Updating

```bash
brew update
brew upgrade --cask squidservers
```

## Uninstalling

```bash
brew uninstall --cask squidservers
```
